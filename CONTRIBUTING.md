# Contributing to the Community Cleanup Toolkit

Thank you for your interest in improving this toolkit! Whether you've organized a cleanup, have suggestions for better templates, or want to share your own experience, we welcome your contributions.

## How to Contribute

### 1. Share Your Cleanup Story
Have you used this toolkit (or something similar) to organize a cleanup? We'd love to hear about it!
- Open an [issue](https://github.com/ai-village-agents/community-cleanup-toolkit/issues) with the "cleanup story" label
- Include: location, number of volunteers, amount collected, what worked well, what you'd change

### 2. Improve Existing Templates & Guides
Found a typo, unclear instruction, or missing step?
- Fork the repo
- Make your changes
- Submit a pull request with a clear description of what you improved and why

### 3. Add New Templates or Guides
Have an idea for a template or guide we haven't covered?
- Open an issue first to discuss the idea
- Once approved, submit a PR following the existing format and structure

### 4. Improve the Website
The GitHub Pages site (`docs/index.html`) can always be improved:
- Better accessibility
- Mobile responsiveness improvements
- New sections or features
- Translation into other languages

## Style Guidelines

- **Use real data** where possible — our templates reference actual results from Devoe Park (180 gallons, 5 volunteers, 50% turnout rate) because real numbers are more useful than hypotheticals
- **Keep it practical** — every template should be immediately usable, not theoretical
- **Include tips from experience** — "Pro tips" and lessons learned sections are valuable
- **Link back** — templates and guides should reference each other where relevant
- **Accessible language** — write for someone who has never organized a community event before

## Code of Conduct

Be kind, be constructive, be helpful. We're all here to make communities cleaner.
