# 📋 Volunteer Signup Form Template

How to create a volunteer signup form for your park cleanup event.

## Recommended: Google Forms

Google Forms is free, easy to set up, and exports data to Google Sheets for easy management.

### Fields to Include

| Field | Type | Required? | Why |
|-------|------|-----------|-----|
| Full Name | Short text | ✅ Yes | So you know who's coming |
| Email Address | Short text | ✅ Yes | For confirmation emails and day-of updates |
| Phone Number | Short text | ❌ Optional | Emergency contact / last-minute coordination |
| How many people in your group? | Number | ✅ Yes | Accurate headcount for supplies |
| Which cleanup are you signing up for? | Dropdown | ✅ Yes | If you have multiple locations/dates |
| How did you hear about us? | Multiple choice | ❌ Optional | Track which outreach channels work |
| Accessibility needs | Long text | ❌ Optional | Ensure the event is inclusive |
| T-shirt size | Dropdown | ❌ Optional | Only if you're providing swag |

### Form Header Text (Copy-Paste)

```
🌿 [Park Name] Community Cleanup — Volunteer Signup

Join us for a community cleanup at [Park Name]!

📅 Date: [Date]
⏰ Time: [Start Time] – [End Time]
📍 Location: [Address / Meeting Point]

What to bring:
- Comfortable clothes you don't mind getting dirty
- Closed-toe shoes
- Water bottle
- Sunscreen (if sunny)

We'll provide trash bags and gloves. If you have your own grabber/picker tool, please bring it!

Questions? Email [your email] or open an issue at [GitHub repo URL].
```

### Form Confirmation Message

```
Thanks for signing up for the [Park Name] cleanup! 🎉

We'll send you a confirmation email closer to the event with final details.

📅 [Date] at [Time]
📍 [Address]

See you there!
```

## Alternative: GitHub Issues

If your audience is tech-savvy, you can use a GitHub Issue as a signup form:

1. Create an issue titled "Volunteer Signup — [Park Name] Cleanup [Date]"
2. Pin it to the repo
3. Ask volunteers to comment with:
   - Name
   - Number of people
   - Whether they can bring supplies

**Pros:** Public, transparent, easy to track
**Cons:** Requires GitHub account, less accessible for general public

## Alternative: Simple Spreadsheet Link

Share a Google Sheets link with edit access. Create columns matching the fields above. Simple but less polished.

## Tips

- **Keep it short.** Only ask for what you actually need. Every extra field reduces signups.
- **Send confirmation emails** within 24 hours of signup. People forget what they signed up for.
- **Day-of reminder** the morning of the event significantly improves turnout.
- **Over-recruit by 50%.** If you want 10 volunteers, aim for 15 signups. No-show rates are real.
- **From our experience:** We had 10 signups and 5 showed up (50% turnout rate). This is normal!
